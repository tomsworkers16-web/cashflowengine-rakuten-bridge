# CFE #001 記事制作品質基準（B案評価の反映）
更新日: 2026-11-16
状態: 編集ルールの提案・試験仕様。公開／自動投稿／main マージは未承認。

## 背景と目的
水切りかごの記事制作比較で、オーナーはA案を「一般的で浅い」、B案を「購入時に見落としがちな注意点があり、一歩踏み込んでいる」と評価した。
「B案の文章を固定する」のではなく、読者の意思決定に資する具体性を生成・検査の要件とする。
記事閲覧数そのものより、読者の問題解決と合法的な成約・最終利益を優先する。

## 生成フロー（公開前）
1. 読者の困りごとを具体的に1つ設定する。解決できる商品候補と、商品を勧めない方が良い条件も列挙。
2. 商品の寸法・構造・素材・設置条件・最新価格・在庫・レビューを情報源と取得日時つきで確認。確認できない項目は不明と記録し、事実として記述しない。
3. 記事構成: 冒頭で悩みを具体化 → よく見落とされる判断条件を少なくとも3つ → 条件の確認方法 → 向く人／向かない人 → 商品の根拠ある特徴 → 注意点 → 必要な広告表記と適正なリンク。
4. 各注意点には「何が問題になるか」「購入前にどう確認するか」を対で記載。一般論だけの注意点は差し戻し。
5. 最終チェックを通過したもののみ「公開候補」にする。公開・外部送信は必ずオーナー事前承認。

## 品質ゲート（各0〜2点／合計12点）
- 読者課題の具体性：0=曖昧、1=課題は具体、2=利用状況まで明確
- 見落としやすい判断材料：0=なし、1=1〜2点、2=3点以上を確認法つきで説明
- 意思決定支援：0=宣伝のみ、1=利点中心、2=適合・不適合双方を記載
- 商品事実の裏付け：0=不明な断定、1=一部確認、2=重要な仕様・注意点に根拠
- 独自の情報価値：0=誰でも思いつく説明、1=具体例あり、2=実用的な比較・検討手順あり
- 誠実な収益導線：0=PR不明・過剰訴求、1=表記あり、2=必要な表示と自然な導線
**合格基準（暫定）**: 10点以上、かつ「商品事実の裏付け」「誠実な収益導線」は各2点必須。架空体験、根拠のない性能断定、画像権利不明は点数に関係なく不合格。
この点数は編集上の仮基準であり、成約率改善を実証したものではない。

## 水切りかご試験の確認ポイント
- 設置スペース: 外寸だけでなく蛇口・棚・壁・作業動線との干渉
- 水の流れ: 排水の向き、シンクとの位置関係、水受けの手入れ
- 容量と使い勝手: 食器の形・調理器具・家族人数との相性
- 手入れ: 洗いやすさ、パーツの着脱、乾燥のしやすさ
※これらは検討観点であり、特定商品に該当するという未検証の主張ではない。

## 成果検証
記事単位で draft_id / 商品ID / 公開先 / 公開日時 / 情報ソース / 品質点 / 表示数 / クリック数 / 成約数 / 確定報酬 / 費用 / 実利益 を記録。
初期はB案方式の記事2〜3本を小規模検証し、公開後の閲覧・クリック・成約を比較。母数が小さい段階では優劣を断定しない。
固定費・API費・運用工数を含む収益性を確認し、継続・改善・撤退を判断。

## 権限・実装上の留意点
この文書は記事制作工程の設計。既存の生成コードに反映済みであること、実際に品質ゲートが自動実行されることは意味しない。
他の承認済み仕様・CLAUDE.mdに矛盾する場合はそれらを優先。秘密情報を記録しない。
