# Cash Flow Engine #001: 読者価値型メディア MVP (2026-11-10)

## 目標
短期収益化を止めずに、商品を売る投稿ばかりのアカウントから、便利な商品や生活の工夫を発掘・比較するメディアへ移す。

## 初期投稿配分（標準3枠/日）
- 朝: 実用的な読み物・選び方（非PR、商品リンクなし）
- 昼: 楽天アフィリエイト（明示的な【PR】、有効なリンクを末尾に残す）
- 夜: 読者向けの読み物、発見、比較を日付でローテーション
- 週21枠のうち昼7枠を収益枠として維持。比率は仮説であり実測により見直す。
- 追いかけ投稿（catch-up）は無理な商品広告にせず読み物枠にする。投稿失敗時の既存安全制限を維持。
- 無根拠な利用体験、ランキング実績、販売増加、商品効能の断定は禁止。

## 楽天調査レーン（売上実績の断定ではない）
- niche_proxy (3/5): 商品検索APIの標準関連度順。適度なレビュー数・評価・価格を優先。長期間売れ続けている証明ではない。
- emerging_proxy (1/5): 更新日時の新しい商品を探索。更新日≠発売日、レビュー数が少ない≠ヒット予兆。
- popular_proxy (1/5): レビュー数順。レビュー件数は販売数量・SNS話題性ではない。
- 各候補はAPIで確認できる情報だけを採点。競合SNS・時系列売上・真のロングセラー判定は未実装。
- 楽天APIの429時は従来の再試行抑制を維持。独立した読み物枠は投稿可能。

## 安全と権利
- このPRでは .env・本番・配信設定・自動返信を変更しない。M8への配布はmain統合後、オーナー承認と実機確認が必要。
- 商品画像は権利確認済み素材のみ。画像の自動公開を勝手にONにしない。
- A8等は次の拡張段階。案件固有の条件を取得できるまで架空のサービス案件を作らない。
- PR表示は冒頭【PR】に統一し、投稿末尾のアフィリエイトリンクは完全保持する。

## KPIと判定
- 読者価値: 表示/投稿、返信、プロフィール遷移、フォロワー純増
- 収益: 楽天クリック、成約件数、確定報酬、経費を引いた実利益
- ジャンル別: 発見・比較・実用ガイド・収益案件、研究レーン、投稿曜日・時刻を記録
- まず7〜14日で投稿内容の偏り・品質を確認。成約の少ない段階で優劣を断定しない。
