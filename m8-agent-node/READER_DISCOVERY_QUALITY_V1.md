# ラクミツ記事品質 v1 — 読者の「なるほど」を優先する

## 背景
2026-11-16に実施した水切りかごの記事制作テストでは、A案（置き場所への共感）よりB案（水の流れる方向・掃除のしやすさ等、購入前の具体的注意点）が高評価。理由は「誰でも分かる一般論」より「知らなかった確認点」を示すほうが記事そのものに価値があるため。

### 承認された編集方針
- 共感は導入手段であり合格条件ではない。
- 1記事に最低1つ、実用的かつ根拠を確認できる具体的な発見・選び方を含める。
- 導入で読者の興味を引く → 新しい発見 → 実用的な判断軸 → 関連商品の紹介。ただし文章を定型化しない。
- **未検証の製品性能・実体験・口コミ・人気・効果・割引率は創作しない。**
- リンクをクリックせず記事を読んだだけでも役に立つ内容にする。
- 最終判断は表示数だけでなくフォロー/クリック/成約/確定実利益。自動返信による認知拡大は投稿品質改善の後。

## 今回の実装
- `src/magazine-writing-workflow.js` の writer brief を `reader-discovery-v2` に更新。新発見と具体的な確認方法を記事制作の必須指示に追加。
- `src/magazine-editorial-quality-gate.js` の編集審査基準：
  - 新しい気づき 30点
  - 具体性・実用性 25点
  - 事実確認・根拠 20点
  - 自然な文体 15点
  - 商品との適合 10点
  - 合計80点以上かつ新発見20点以上、具体性18点以上、根拠15点以上が必要
  - レビュアーに `insightStatement`、`actionableTakeaway`、`claimChecks` とその根拠URLを要求。未確認の主張があれば差し戻す。
- `src/magazine-demand-aware-writing.js` から品質ゲートを呼び出し、合格しなければ広告付き原稿を作成しない（`quality_revision_required`）。

## 限界・安全性
- この採点は**レビュアーの編集判断（仮評価）**であり、実証された記事品質や売上改善を意味しない。外部ライター/レビュアー実接続はまだ未実施。
- レビュアーが `source_verified` を名乗っても、URLが実際の記載内容と一致することの**独立検証は未実装**。誤った根拠と誇大広告を避けるため、オーナー承認を必須とする。
- `magazine-writing-pilot.js`（需要情報を使わない従来パイロット）には本ゲートは現時点で未適用。融合型の新経路に先行適用している。
- 全戻り値は `publicationAllowed:false`。mainへのマージ・投稿・課金・本番変更なし。
- PR #100 作業ブランチに保存。
