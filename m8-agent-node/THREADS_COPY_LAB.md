# Threads投稿文の集客改善・オフライン試作（2026-11-10）

## 背景
11月4〜10日の確認ではThreads投稿16件、うち収益投稿5件の観測済み累計表示回数の合計35回。楽天日別実績の確認できた5日間ではクリック0件。少ない表示母数では「どの文面が良い」と証明できない。

## 試作内容
- 既存の商品名・価格・用途記載・楽天アフィリエイトURLだけから3案を作る。
  1. `problem_question`：商品が解決し得る困りごとに触れる
  2. `buyer_checklist`：購入前の注意点を強調
  3. `product_identity`：従来に近い商品紹介型（比較対象）
- あくまで試作であり投稿処理には接続しない。文面に「使った」「必ず」「最安」「爆売れ」等の未検証表現を含めない。
- `【PR】` 表示、元のURLの完全保持、500字以内をチェック。価格・送料・商品の仕様・画像利用権は別途確認が必要。
- どれが集客に有効かは**実際の投稿データが蓄積してから**比較する。自動勝者選定はしない。
- 実装：`m8-agent-node/src/threads-copy-lab.js` の `createRevenueCopyHypotheses(item)` / `auditDraft(text,...)`。
- 今回はテストと開発準備のみ。M8本番設定、投稿文、自動公開、日次投稿上限、自動返信は変更しない。main統合は別途承認。
