# Cash Flow Engine：融合記事の小規模A/B実験計画（未公開）

## 実装範囲
`src/magazine-fusion-trial-plan.js` は既存と融合の**同一商品・異なる記事切り口**の原稿が両方とも審査待ちである場合だけ、実験計画案を出す。

- 既存システムの自動投稿設定（07:30、12:30、19:30）は変更しない。
- 同じ時間帯で交互割付（AB/BA）。各群3件（計6件）をデフォルトとするが、これは有意性のあるサンプル数ではない。
- 占有済みスロットは候補から除外可能。ただし手元にライブ予約キューがない場合、**空き時間は未確認**である。
- 計画は公開指示ではない。全行に `owner_approval_required`、`not_published` を明記する。
- 価格・在庫・送料・商品仕様・広告リンクは公開直前に再確認する。保存済み2026-11-11スナップショットの価格は現在の保証ではない。
- 現段階では投稿別の楽天売上・報酬帰属ができず、収益面の勝敗は判断できない。
- 人手による確認・SNS投稿予約・実験割当ID登録は**未接続**。この計画はその準備のみ。
