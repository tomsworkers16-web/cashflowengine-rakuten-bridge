# 楽天アフィリエイト成果レポートの自動取り込み（安全な第一段階）

## 実装済み
- 楽天公式管理画面からPC用の「期間別成果レポート」をCSV保存すると、指定フォルダーにあるCSVを23:45以降の夜間評価で自動取り込みします。
- 指定フォルダーは**専用フォルダーのみ**。通常の「ダウンロード」フォルダー全体は監視しません。
- CSVのヘッダー、日付、数値を検証。CSV以外や不正な形式は取り込まず、元ファイルは削除・移動しません。
- 取り込み済みファイルのSHA-256で同一ファイルの再コピーを避けます。CSV内容が更新されて再ダウンロードされれば別ファイルとして保存し、同日データは日次スナップショットとして置換します。
- 報酬は**未確定**として扱い、注文と報酬を実利益や入金額と誤表示しません。
- オプトイン設定がない場合は無効のままです。

## M8で将来有効化するとき
PowerShellで専用フォルダーを作成してください。通常の「ダウンロード」に置かないでください。

```powershell
New-Item -ItemType Directory -Force -Path "C:\AI-Factory\rakuten-report-downloads"
```

M8の `.env` に次の1行を追加し、監視を有効にします。

```dotenv
RAKUTEN_REPORT_DOWNLOAD_DIR=C:\AI-Factory\rakuten-report-downloads
```

この設定だけでは管理画面のログイン・CSVダウンロードそのものは自動化されません。公式レポートにログインしたブラウザで、CSVを**専用フォルダーへ保存**する操作は必要です。

手動で夜間分析を実行して検証可能です（投稿は行いません）。

```powershell
npm.cmd run night-eval
```

結果の `affiliateCapture` と `affiliateImport` を確認してください。

## 今後の完全無人化
楽天側のUIや認証条件を確認したうえで、**ログイン状態のある許可済みブラウザで、公式のCSVダウンロード操作**を自動化する必要があります。ログイン認証の回避・非公開APIの無断利用・ダウンロードされた成果の創作は行いません。

公式説明：https://affiliate.rakuten.co.jp/guides/report/

CSVレポートの実績反映には時間差（公式ガイドで12時間以内）があるため、当日のレポートが未取得でも「成果0」とは断定しません。
